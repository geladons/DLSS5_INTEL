# Code of conduct

We are a small research project with big ambitions. A few ground rules:

1. **Be kind, be direct.** Critique code and ideas, never people. No
   harassment, personal attacks, or discrimination of any kind.
2. **Evidence over opinion.** Claims about behavior or performance should
   cite logs, dumps, or reproducible steps. The repo's culture is measured
   numbers > hot takes.
3. **Honest status.** This demo has known weaknesses (performance, overlay
   edge cases). Do not oversell, do not astrotrot, and call out hype when
   you see it — including our own README.
4. **Respect the legal lines.** No weights, no leaked data, no anti-cheat
   discussion, no NVIDIA code (see SECURITY.md).
5. **Languages.** English is the default for issues/PRs/code; Russian is
   welcome too (the core team is bilingual).

Unacceptable behavior may be reported to the repository owner via GitHub.
Maintainers may remove, edit, or reject comments, commits, code, issues and
other contributions that violate this code.
