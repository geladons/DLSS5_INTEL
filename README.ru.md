# DLSS5_INTEL

**DLSS 5 Neural Rendering, работающий вживую на Intel Arc — фанатский исследовательский проект.**

Проект берёт настоящую нейросетевую модель DLSS 5 (71-блочный граф DLSSNR) и
запускает её на **видеокартах Intel Arc** через Vulkan
(`VK_KHR_cooperative_matrix`, XMX-ядра) вместо тензорных ядер NVIDIA. Обработка
идёт **в реальном времени на презенте кадра** — для Vulkan-игр через implicit
Vulkan-слой, для DirectX 9/10/11 — через DXVK + тот же слой, для DirectX 12 —
через собственный DXGI-прокси. Режим «экран/окно» обрабатывает весь десктоп
или отдельное окно через DDA-захват и кликабельный поверхностный Vulkan-оверлей.

> ⚠️ **Фан-проект. Не продукт.** Не аффилирован с NVIDIA и Intel и не
> одобрен ими. Мы **не используем код NVIDIA** и **не распространяем веса
> модели** (проприетарные данные NVIDIA). DLSS и NVIDIA — товарные знаки
> NVIDIA Corporation. Всё здесь — исследование и инженерная демонстрация.

## Как это работает (коротко)

```
кадр игры ──present──► ┌ Vulkan-слой / DXGI-прокси / DDA-захват ┐
                        │ заголовок 16 байт + BGRA, TCP 127.0.0.1:47990 │
                        └──────────────► даемон m11d ◄──────────────────┘
                                       decode → features → featpack
                                       → 71-блочный чейн DLSSNR (упор в GEMM)
                                       → head → residual → высокочастотный фильтр
                                       → эхо-подавление (feedback accumulate)
                                       → compose (крутилки gain + blend)
                                       → encode → readback ──► обратно в свопчейн
```

- **Vulkan-игры** — implicit Vulkan-слой перехватывает `vkQueuePresentKHR`,
  отправляет кадр даемону и записывает обработанный кадр обратно.
- **DX9/10/11** — DXVK для конкретной игры гонит D3D через Vulkan, дальше
  работает тот же слой.
- **DX12** — прокси `dxgi.dll` (vtable-хук на `Present`) делает тот же
  раундтрип напрямую.
- **Режим экрана/окна** — DDA-дубликация десктопа → CPU-мост → тот же чейн →
  полноэкранный topmost кликабельный Vulkan-оверлей.
- **Менеджер (M13)** — Python/Tk только на стандартной библиотеке:
  автоустановка, поиск игр, деплой/запуск на игру, две живые крутилки,
  внутриигровой оверлей, интерфейс EN/RU.

Подробности, карта модулей и разбор производительности:
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Возможности

- Живая нейропостобработка в **Vulkan, DX9, DX10, DX11, DX12**
- **Автоинъект**: нужные DLL копируются рядом с исполняемым файлом игры под
  определённый API (бекап перед перезаписью, восстановление поддержано)
- **Автопоиск игр**: библиотеки Steam, манифесты Epic, реестр GOG, скан всех
  дисков с разбором PE (импорты, delay-load, wide-строки D3D) — находит
  настоящий рендерер и его битность
- **Две живые крутилки** — `gain` (сила эффекта, 0–16) и `blend` (микс
  эффекта, 0–1; при 0 — побитовый прозрачный проход) — в шапке менеджера и во
  внутриигровом оверлее; сброс каждого слайдера; сохраняются в конфиге
- **Фоторежим** — `CTRL+ALT+G` замораживает сырой кадр, каждый поворот крутилки
  перерабатывает *исходный* кадр на лету, закрытие панели продолжает игру
- Горячие клавиши: `CTRL+ALT+G` оверлей · `CTRL+ALT+X` пауза/возобновление ·
  `CTRL+ALT+Q` выгрузить слой
- Интерфейс EN/RU
- Валидация бит-в-бит против PyTorch-эталонов (features 15/16 каналов
  bit-exact, head meandiff ≈ 0.0083 = уровень fp16-шума)

## Требования

- Windows 10 / 11 (проверено на Windows 11)
- **Intel Arc с 16 ГБ VRAM рекомендовано** (проверено: Arc Pro B50; путь
  обработки резервирует ~12 ГБ, поэтому даемон и оверлей экрана не могут
  работать одновременно — менеджер это контролирует)
- Vulkan 1.3+ с `VK_KHR_cooperative_matrix` (класс Xe2)
- Python 3.10+ для менеджера (лаунчер находит его сам)
- Веса модели — **не входят в комплект**, см. ниже

## Быстрый старт (релизный бандл)

1. Скачайте релизный бандл из [Releases](../../releases) (или соберите из
   репозитория скриптом
   [`release/assemble-release.cmd`](release/assemble-release.cmd)).
2. Положите файл весов в папку `weights\` бандла — точное имя и формат в
   [docs/weights-format.md](docs/weights-format.md).
3. Запустите **`DLSS5 Manager.vbs`** (двойной клик; чёрного окна консоли нет).
4. Вкладка «Игры» → выберите карточку игры → **«Включить DLSS 5»** (один запрос
   UAC для игр из Program Files) → **«Играть»**.
5. В игре: `CTRL+ALT+G` — панель управления на замороженном кадре.

**Предупреждение об античите:** не включайте в онлайн-играх (PUBG, CS2,
GTA Online, всё с ядерным античитом) — DLL-инъекция может быть расценена как
чит. Только одиночные игры.

## Веса

Веса модели DLSSNR — **проприетарные данные NVIDIA и не распространяются** — ни
в репозитории, ни в релизном бандле. Для запуска демки нужен ровно один файл:

| | |
|---|---|
| Имя файла | `dlssnr-logical.safetensors` |
| Формат | Safetensors, раскладка `dlssnr-logical-v18` |
| Содержимое | 649 тензоров (579 × F16, 70 × F32), 71 группа блоков сверху — стек DLSSNR в стиле ViT |
| Размер | ~291.5 МБ (≈325 МБ резидентно в VRAM) |
| SHA-256 | `203b0af3be94078cfd17a71adc4628cffd960a4d435e4820fe994ddd9493a6a5` |
| Куда | папка `weights\` бандла или любой путь через `--weights` |

Как получить такой файл — ваше дело и дело вашего локального права; загрузчик
просто читает формат Safetensors выше. Детали:
[docs/weights-format.md](docs/weights-format.md).

## Стенд для тестов

Всё живое тестирование шло на виртуальной машине:

- **ВМ:** Windows 11, проброс GPU — 1× **Intel Arc Pro B50 16 ГБ**,
  32 ГБ ОЗУ, 10 ядер CPU
- **Хост:** Supermicro, два **Xeon E5-2680 v4**, 110 ГБ ОЗУ, 2× Intel Arc B50
- **Стрим:** рабочий стол ВМ используется через **Sunshine / Moonlight**
  (2560×1440) — именно так проверялся вывод оверлея, потому что оконные
  Vulkan-flip поверхности на этом стенде невидимы для локального GDI/DDA

Записи и скриншоты демо: GTA IV (DX9) — меню, экраны загрузки, игровые
интерьеры.
